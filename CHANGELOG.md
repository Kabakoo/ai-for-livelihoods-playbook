# Changelog

## 2026.09-v7 — September 14, 2026

Initial public source release of [Kabakoo Academies’](https://www.kabakoo.africa/) [Building AI Applications for Livelihoods](https://playbook.kabakoo.africa/).

- Ten published chapters and ten browser working tools, with learner stories, interface examples, and explanatory drawings.
- History of Kabakoo’s AI work and collective acknowledgments.
- A standalone Quarto build with static checks and browser verification scripts.
- Citation, contribution guidance, text and code licenses, and separate asset terms.

Read web edition 7 at [playbook.kabakoo.africa](https://playbook.kabakoo.africa/).
